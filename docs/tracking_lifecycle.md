# 追踪启停与手动预览

F310配置中tracking=5，对应RB右肩键。先按Start解锁，再按RB切换追踪开启/关闭。
手动模式下快速/精确选择框与重置按钮禁用；画面显示YOLO未启用。

启动时不创建追踪器；只有RB开启追踪时才构造所选追踪器并加载模型。
关闭、右摇杆接管或目标丢失退回手动时释放追踪器、清空预测状态。
手动预览不调用YOLO、追踪Framer或逐帧追踪记录。
自动补光的图像均值计算独立于YOLO，继续正常工作。

Core ML ALL由系统选择CPU/GPU/ANE；本改动确保手动模式无YOLO/Core ML推理调用，
并不宣称追踪时所有计算只在NPU完成。视频25fps是输入流目标值，界面实测帧率允许小幅波动。

验证：模拟追踪对象在手动模式处理10帧，推理和追踪控制调用次数均为0；
检查按需创建、释放、模型失败、手动模式修改偏好、摇杆接管与控件启停。
