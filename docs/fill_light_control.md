# 补光灯界面与控制

仪表盘同一行显示“画面亮度”（预览裁剪后图像平均亮度）和“补光灯亮度”（Pi成功写入的PWM百分比）。
驱动板故障或Pi状态超过3秒未更新，PWM显示为`---`。这不是光输出或照度测量。

右侧补光灯滑块范围0–100%。默认手动，勾选自动后滑块禁用并跟随自动设定值。
自动每0.5秒按反向线性范围映射画面亮度：默认画面20%对应PWM 0%，画面0%对应PWM 100%，超出范围钳制到0–100%。
“自动”复选框位于滑块左侧，与滑块和百分比同一行。设置→补光灯控制可修改两个画面亮度端点，保存后立即生效并写入host_config.yaml的lighting段。
无有效新画面或驱动板不可用时暂停自动调整。取消自动保留当前设定，允许手动拖动。
手柄LT/RT返回手动模式并按原来的10%步长调整；GUI与手柄共用指令路径。

Pi回报tel.pi_status.light_pwm_pct，只有成功写入硬件后才更新。上位机合并滑块事件并重试
未获状态确认的UDP灯光命令（最多5次/秒）。Pi灯光初始化为关闭。

使用PCA9685 CH5，现有共用PWM频率仍为50Hz；本次没有改变舵机频率。
自动亮度参数为初始默认值，实际水下效果仍需测试；相机自动曝光和场景变化都会影响平均亮度。

验证：29项检查通过；实际UI设置20%时，CH5寄存器[0,0,51,3]对应约20%，Pi回报及仪表盘一致。
自动模式确认滑块禁用、PWM从20%缓慢增加；取消自动确认恢复手动操作。
