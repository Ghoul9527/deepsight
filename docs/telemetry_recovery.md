# Pi遥测自动恢复

MessageRouter独立监控遥测任务：异常/意外退出后1秒重启；超过5秒未完成
包含Pi心跳的一轮发送时取消并重启。监测周期1秒，因此卡住后的恢复检测约5–6秒。
每批最多处理100条Pico或STM32消息，避免积压持续占用遥测循环。
正常关闭会取消监督任务与工作任务，不触发恢复。

日志：Pi上的 `/home/tony/deepsight/logs/pi/deepsight-pi.log`。
文件记录INFO及以上：故障堆栈、重启计数、恢复、每60秒健康状态和Pico队列长度。
单文件5MiB，保留3份历史，含当前文件最多约20MiB。控制台/journal继续使用原日志级别。

该监测证明的是Pi遥测发送任务持续工作；UDP无交付确认，不能据此保证上位机已收到。
物理断网期间不会凭空恢复连接，硬件断链也不由此功能修复。
现有systemd的Restart=always继续负责进程退出后的服务重启。

验证：本机自动测试覆盖发送失败、卡住、意外退出、关闭和队列积压；Pi上使用
独立模拟Host/Pico对象进行发送失败及卡住注入，确认自动恢复和日志写入，未向硬件发送控制命令。
