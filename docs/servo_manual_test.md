# 舵机逐个手动测试

双击`scripts/启动舵机手动测试.command`，或在仓库根目录运行：
`.venv-coreml/bin/python -m deepsight_host.servo_tester`

1. 点击“连接Pi / 进入测试”。程序通过SSH暂停Pi主服务并独占PCA9685，关闭全部舵机PWM。
2. 选择Yaw CH0、Pitch CH1、Roll CH2、左CH3、右CH4，或“全部舵机”。全部模式对五个通道设置同一脉宽。
3. 默认脉宽范围1000–2000μs，中位1500μs。勾选“开始输出到所选舵机”才发送脉宽。
4. 拖动逻辑角度、使用±1°/±5°微调，或直接设定500–2500μs。
5. 切换通道自动停止输出并复位设定为1500μs，需要重新勾选才驱动新通道。
6. “停止全部舵机PWM输出”取消选择并关闭所有舵机脉冲；这不等于切断舵机电源。
7. 关闭测试窗口会先停止PWM，再恢复原先运行的Pi主服务；主服务会按正常配置初始化舵机。

测试时上位机原窗口可能显示组件失联，因为Pi主服务被暂时停止；相机独立视频通道可继续。
防抖和尾翼联动的配置不会由测试程序修改；本次测试前已由三轮测试暂停。
程序使用SSH密钥认证，服务器脚本路径为`/home/tony/deepsight/scripts/servo_manual_bridge.py`。
远端日志位于`/home/tony/deepsight/logs/servo-manual-*.jsonl`。

角度仅为逻辑映射，寄存器回读不是舵机实际位置或供电测量。
连续旋转舵机可能将PWM解释为速度/方向；需核对具体型号。
