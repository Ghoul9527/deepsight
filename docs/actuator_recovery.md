# PCA9685自动恢复

I²C写入失败后暂停执行器输出，清空舵机/灯光命令缓冲，Pi和Pico遥测继续。
后台每1秒读取PCA9685 MODE1，连续两次读成功后重新配置PWM频率、舵机默认角度和补光灯关闭。
只有全部初始化成功，才清除故障；上位机随后从tel.pi_status.actuator_ok获得正常状态。
不回放断链期间命令。重建横滚/尾翼控制器以清除旧的姿态和速度历史。
上位机自动补光或新的手柄指令可在恢复后重新设置输出。

日志记录首次故障、每30秒一次恢复等待原因、恢复成功事件。
位置：Pi的logs/pi/deepsight-pi.log及systemd journal。
首次初始化就缺板也进入同一恢复流程，不再必须重启服务。

验证：16项自动检查，包含断链隔离、遥测监督、连续探测、初始化失败与旧命令清除。
Pi上独立模拟故障，使用实际0x40只读探测，连续两次成功后确认故障清除；该模拟不写舵机输出。
