# 已安装舵机标定与默认限位

依据用户提供的12V定位舵机参数：500–2500μs，中位1500μs，中位两侧各约175°。
这是名义线性标定，不是角度传感器实测；360°为标注机械极限，不作为默认工作行程。

正常控制默认限制：

| 舵机 | 通道 | 相对中位范围 | 名义PWM范围 |
|---|---|---|---|
| Yaw | CH0 | ±15° | 1414.3–1585.7μs |
| Pitch | CH1 | ±15° | 1414.3–1585.7μs |
| Roll | CH2 | ±15° | 1414.3–1585.7μs |
| 左舵板 | CH3 | ±45° | 1242.9–1757.1μs |
| 右舵板 | CH4 | ±45° | 1242.9–1757.1μs |

协议为兼容现有上位机仍使用90作为回正，`angle - 90`表示相对中位的物理偏转角。
Pi驱动层在角度转换为脉宽前执行限幅，即使上游发送越界角度也不会扩大正常控制行程。
标定位于pi/src/deepsight_pi/servo_calibration.py和configs/pi_config.yaml的hardware.servo_calibration；
每个舵机的max_deflection_deg可覆盖默认限位。

独立测试工具直接设定脉宽，保留500–2500μs检修能力，不套用正常控制的±15°/±45°限幅。
测试工具中的0–180°仍是测试范围内的逻辑刻度，不能当作实测物理角度。

传感器横滚防抖与尾翼联动保持关闭；本次部署不重启正在使用的独立测试程序。
退出测试、恢复Pi主服务后载入新标定与限位。
